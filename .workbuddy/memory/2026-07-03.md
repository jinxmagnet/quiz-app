# 2026-07-03

## 任务：quiz-app 项目优化

### 修复的 Bug
1. **selectBank 清除记录问题**：从首页重新进入同一题库时不再清除答题记录。`selectBank` 现在只在新旧题库名不同时才重置。
2. **setPageMode 清除记录问题**：切换答题/学习模式不再清除进度。

### 新增功能
1. **收藏功能**：每道题右上角添加星标收藏按钮，收藏状态持久化到 localStorage。
2. **复习模式**：新增"全部/错题/收藏"三个筛选模式，可只复习错题或收藏的题目。
3. **返回按钮**：答题页顶部左侧添加返回首页按钮。
4. **首页进度显示**：题库卡片上显示答题进度条和已答/正确统计。
5. **空状态**：复习模式下无题目时显示空状态提示。

### UI 重设计
- 全局配色改为 Indigo 主题（#6366f1），更柔和专业
- CSS 变量统一管理颜色、阴影、圆角
- 分段控制器（Segmented Control）替代原来的按钮组
- 选项按钮增加字母圆标，状态更明确
- 卡片阴影、圆角、间距整体优化
- 结果页增加完成图标和全对提示
- 网格弹窗增加背景模糊效果
- 全局添加 antialiased 字体渲染
